# Africa Agro Export Buyers Database — Architecture

Year-independent, extensible database of African agricultural export buyers.

Planned layers:
- Domain: buyers, agricultural products, verification, research provenance.
- Registry: normalized and deduplicated records.
- Contracts: validation and service/API boundaries.
- Schema: persistent storage and migrations.
- Research: future approved source discovery and evidence collection.
- Agent integration: future specialist agent coordinated through the shared AfriAgent Harness and AfriAICommand Agent.

This scaffold is not active and does not collect or store live data.
