# Roadmap

1. Complete scaffold and review architecture.
2. Define buyer/product schemas and validation contracts.
3. Define source provenance, verification, deduplication, and confidence rules.
4. Implement persistence using AfriDigital shared database infrastructure.
5. Implement controlled research and evidence collection.
6. Add tests, security controls, bounded operations, and auditability.
7. Integrate a specialist research agent through the shared AfriAgent Harness.
8. Return results to AfriAICommand Agent for coordination and reporting.
9. Enable capabilities only after explicit validation and approval.

No live research, database provisioning, jobs, deployments, or agent activation in this scaffold phase.
